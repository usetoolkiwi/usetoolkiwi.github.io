QR Code Generator

Turn any link or text into a QR code. Free forever, no sign-up, and the code never expires.

How to use the QR Code Generator

  1. Type or paste a link, text, phone number or email.
  2. Choose a size and colours. Keep a dark colour on a light background so phones can scan it.
  3. Download as PNG for everyday use or SVG for print.

Frequently asked questions

Do these QR codes expire?

No. The code is a static QR code — the link is written into the pattern itself, so it works forever and needs no account.

Can I use the QR code commercially?

Yes, on menus, flyers, business cards and packaging — free for any use.

Which format is best for printing?

SVG, because it stays perfectly sharp at any size.

What does error correction do?

Higher error correction lets the code still scan when part of it is dirty or covered, but makes the pattern denser.
